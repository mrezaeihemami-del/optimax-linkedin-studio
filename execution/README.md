# EXECUTION TOOLS (Layer 3: Doing The Work)

> This directory contains deterministic scripts (Python, Node.js/TypeScript, Shell).
> They handle data transformations, API calls, file chunking, scraping, and database persistence.

---

## Why Deterministic Execution?
If an LLM tries to parse 100 pages of text, calculate statistics, or manipulate JSON structures directly in chat, compounded error rates degrade reliability exponentially ($0.90^5 \approx 59\%$).

Pushing complexity into well-tested, strongly-typed scripts leaves the AI agent focused purely on intelligent orchestration, input validation, and decision routing.

---

## Rules for Execution Scripts
1. **Self-Contained & Testable:** Each script must take explicit CLI arguments or environment variables and exit with `0` on success, or non-zero on error.
2. **Fail-Fast:** Throw an explicit error if input is malformed; do not return plausible mock data.
3. **No Hardcoded Secrets:** Always read tokens from `.env` or process environment.
4. **Transient Files to `.tmp/`:** Intermediate files generated by scripts must live in `.tmp/` or `scratch/`, never in root or production directories.
